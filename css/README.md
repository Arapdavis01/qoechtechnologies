# Images

Copy your existing pictures into these exact paths. The site looks for:

```
images/logo/qoech-logo.png      main Q logo (also the favicon and share image)
images/logo/eagle-right.png     eagle animation, flying right
images/logo/eagle-left.png      eagle animation, flying left
images/logo/q-ring.png          Q logo variant used during the animation
images/projects/hardware.jpg    project photos (16:10 shape looks best)
images/projects/agrovet.jpg
images/projects/riverview.jpg
```

Tip: compress project photos (squoosh.app) to under about 200 KB each, so the
page loads quickly on mobile data.
